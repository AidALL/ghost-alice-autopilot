# Ghost-ALICE Autopilot v0.4.0 릴리스 노트

언어: [English](../../release/2026-09-28-release-notes.md) | Korean

## 변경 내용

- 승인된 실행·작업·이벤트·소비한 inbox receipt·승인 이력을 SQLite에 저장합니다. 세션에 연결된 실행은 Core와 트랜잭션을 공유하고, 독립 실행은 별도 DB를 유지합니다.
- 실행 승인과 증거를 정확한 세션·입력·완료 조건·승인 세대에 연결합니다. 같은 승인 계약에서는 진행 상황·예산·OFF를 보존하고, 바뀐 세대는 이력으로 보관합니다.
- 도구 실행 전에 증거 출처를 포착하고 현재 준비 명령을 한 번 안내합니다. 최초 답변 전에 원본 증거를 게시하고, 복구 과정에서도 출처·시각·digest를 유지합니다.
- 현재 입력에 대한 명시적 재승인이 사용자 작업을 유지하도록 하고, 부수적인 행동 계획으로 바뀌지 않게 합니다. 복구 시 유효한 업무 증거와 요청하신 답변을 보존합니다.
- 도구 실행 전 출처 탐색에서 다른 세션만 있는 DB를 건너뛰고, 현재 세션의 권한 오류는 계속 거부합니다. CI는 짝을 이루는 Core 런타임을 지정하고 등록된 두 훅을 검사합니다.

## 호환성과 업데이트

Autopilot 0.4.0에는 공유 SQLite API를 제공하는 Core 0.4.0 이상이 필요합니다. 두 패키지를 함께 업데이트하고 다시 설치해 주세요. 0.2.2에서 추가된 구형 설치기의 어댑터 지원만으로 이번 런타임 요구 사항이 충족되지는 않습니다. 이관 전 구형 기록 프로세스를 중지하고 일관된 백업을 보존해 주세요. 이관된 JSON 파일은 더 이상 원장이 아닙니다. 내부 스키마 버전은 제품 버전과 별도로 유지합니다.

## 검증과 한계

전달된 구현의 기존 격리 평가에서는 최초 완료 게시, 대상·현재 입력 처리, 저장만을 위한 재조회 방지를 확인했습니다. 과거 실패와 평가 한계는 보존합니다. 모든 모델 판단의 정확성이나 종료 훅 거절 시 호스트 화면의 중복 표시 제거를 보장하지 않습니다.

저장소 CI는 대응하는 Core와 함께 실행합니다. compatibility-matrix.json의 과거 플랫폼 근거를 이번 버전의 새 실행으로 바꾸어 표시하지 않습니다. Git 태그와 공개 릴리스 발행은 소스 버전 변경과 별도입니다.

## 라이선스

Apache-2.0 오픈소스 라이선스를 유지합니다.
